## Reflection Questions

**1. What was the most challenging part of this project?**
The most challenging part was implementing the bilingual system (Spanish/English) using JavaScript and ensuring the translation updated all the sections instantly without reloading the page.

**2. What new skills did you learn?**
I learned how to use CSS Grid and Flexbox to make the website responsive, ensuring it looks good on both mobile phones and desktop computers.

**3. How do you plan to improve this project in the future?**
In the future, I plan to add more interactive projects to my portfolio and link my real GitHub and LinkedIn accounts once they are fully updated.
